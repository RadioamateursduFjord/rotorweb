Station

Changer / redétecter le contrôleur

Branche le nouveau contrôleur en USB, puis cherche les ports. La détection envoie seulement des demandes de position, jamais de mouvement. L'ancienne configuration est gardée dans le profil « ↩ Précédent ».

Garder la courseButée, amplitude, zones interdites
Garder la calibrationSinon : calibration et décalage remis à zéro (à refaire)

Test

Maintiens un bouton pour un petit mouvement (« En opération » doit être actif). Si la course ou la calibration a été remise à zéro, va dans Course du rotor puis Calibration.

Élévation

Les contrôleurs GS-232 (K3NG, Yaesu) se calibrent eux-mêmes avec deux commandes :

1Amène le rotor en butée gauche (bouton Gauche maintenu), puis envoie O.
2Amène le rotor en butée droite, puis envoie F (pleine échelle).

Ensuite, corrige l'orientation exacte avec le décalage de l'antenne.

Ce contrôleur se calibre depuis son propre menu (voir son manuel). RotorWeb corrige ensuite l'orientation avec le décalage de l'antenne.

Application mobile

Recherche d'indicatifs

La case « Pointer vers… » accepte un grid, un indicatif ou une ville. Pour la position exacte d'une station, il faut un compte HamQTH (gratuit) ou QRZ.com (abonnement XML). Sans compte, le préfixe donne le pays. Les villes viennent d'Open-Meteo (gratuit).

Le préfixe sert toujours de dernier recours : il donne la direction du pays (approximative pour les grands pays).

La vérification se fait aussi toute seule une fois par jour. Avant d'installer, RotorWeb vérifie la signature de la version ; l'antenne va au repos ; si la nouvelle version ne démarre pas, l'ancienne revient automatiquement. Rien ne s'installe sans ta confirmation.

Source des mises à jour

Sauvegarde des réglages

Un seul fichier avec tout : réglages, contrôleur, calibration, profils, horaires, préréglages, courriels, Home Assistant, comptes. Il est chiffré avec le mot de passe choisi ici : sans ce mot de passe, la sauvegarde est illisible, note-le bien.

Restaurer une sauvegarde

La restauration remplace TOUS les réglages actuels (une copie est gardée sur le Pi), puis RotorWeb redémarre. Aussi possible en terminal : sudo /opt/rotorweb/restore.sh fichier.rwbackup, ou pendant une réinstallation avec install.sh.
